ESP32 Face Lock — Test Page

Safety: This is a starter demo, not secure door-access control. It does not unlock automatically. Test the camera and ESP32 commands first, with the physical lock disconnected. The ESP32's current /open URL has no authentication, so anyone on the same network may be able to trigger it.

If the video does not appear, open http://192.168.43.194:8080 in the second phone's browser and use the Video URL shown by IP Webcam. Some browser/app combinations block cross-device HTTP video; this page cannot bypass that restriction.

Face recognition status

This starter page does not recognize or enroll faces yet. A proper face-matching stage needs a face-recognition model and registered reference image/descriptor. It must be tested before enabling any unlock action.
